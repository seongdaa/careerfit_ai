# CareerFit AI

> 취업·공모전 데이터 기반 맞춤형 AI 포트폴리오 코치


## 프로젝트 개요

문제 정의 : 공모전에 익숙하지 않은 대학생들에게 정보 제공 (필요 역량, 시간 등)


## 기술 스택



| 영역 | 기술 |

|---|---|

| 백엔드 | Python, FastAPI |

| AI API | Gemini 2.5 Flash-Lite |

| 데이터 | Pandas, SQLite, ChromaDB |

| 프론트엔드 | React, Vite |

| 실행 환경 | Docker |
