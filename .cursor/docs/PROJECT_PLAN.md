## 1. 문제 정의

취업 또는 공모전을 준비하면서 가장 불편했던 점은? 
-> 어떤 스킬을 준비해야 할지 모르겠다 
-> 이전 기수를 참고하고 싶다 
-> 어떤 방향성을 가진건지 잘 모르겠다 
-> 시간 투자가 얼마나 필요한지 알고싶다

이 문제를 어떻게 해결하는가 ? 
-> 해당 공모전을 통해 얻을 수 있는 점과 가장 관련있는 직무를 정리해준다
-> 공모전 참여에 필요한 스킬을 정리해 나의 역량과 비교해 부족한 점을 알려준다

## 2. 사용자 정의

- 대상: 공모전에 익숙하지 않은 대학생 


- 사용 시나리오:

1. 사용자가 전공, 보유 스킬, 관심 직무를 입력한다.

2. CareerFit AI가 데이터를 검색해 역량 매칭 결과를 반환한다.

3. 어떤 데이터를 기반으로 답변했는지 출처를 함께 표시한다.



## 3. 데이터 계획

- 취업 공고 컬럼: [회사, 직무명, 요구 스킬, 우대 사항, 지원 자격, 업무 내용, 마감일]

- 공모전 컬럼: [공모전명, 주최, 분야, 참가 자격, 요구 역량, 상금, 마감일]

- 데이터 출처: 강사 제공 목업 CSV (3일차)
